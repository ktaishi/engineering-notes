# 法務・ライセンス

> 最終確認日：2026年11月15日

ソフトウェア開発で確認すべき法務まわりのノートです。OSS のライセンス、AI が生成したコードの扱い、個人情報の保護、契約上の注意点を扱います。
このノートは確認の観点を整理したもので、法的な助言ではありません。判断が必要な場合は、弁護士などの専門家に相談してください。

---

## 基本方針

1. **使っている OSS とライセンスを把握する**
   - 依存パッケージを一覧にし、ライセンスの条件（表示義務、ソースコードの公開義務など）を確認する
2. **AI が生成したコードも、ライセンスの確認の対象にする**
   - AI が既存のコードをほぼそのまま出力することがあるため、特に長いまとまったコードは注意する
3. **個人情報は、取得の段階から目的と範囲を決める**
   - 何を、何のために、どこに、いつまで保存するかを決め、利用規約とプライバシーポリシーに書く
4. **契約で、権利と責任の範囲を明確にする**
   - 成果物の権利、秘密保持、AI ツールの利用、損害の責任の範囲を、契約の段階で確認する

## チェックリスト

### 1. OSS のライセンス

- [ ] 依存パッケージとライセンスの一覧（SBOM など）を作れるか
- [ ] 使ってよいライセンスと、確認が必要なライセンス（GPL などのコピーレフト）を決めているか
- [ ] ライセンスの表示義務（著作権表示、ライセンス文の同梱）を満たしているか
- [ ] コピーレフトのライセンスのコードを、自社の製品に組み込んでいないか（組み込む場合は条件を確認したか）
- [ ] ライセンスの確認を、CI で自動化しているか

### 2. AI が生成したコード

- [ ] 利用する AI ツールの規約で、生成物の権利と、利用者の責任を確認したか
- [ ] AI が出力した長いまとまったコードが、既存の OSS のコードと一致していないか確認しているか（一致の検出機能やスキャンツールを使う）
- [ ] AI が提案した依存パッケージのライセンスを確認しているか
- [ ] AI の利用を、契約や顧客の規定で認められているか確認したか
- [ ] AI ツールに、顧客のコードや秘密情報を入力してよいかを確認したか

### 3. 個人情報の保護

- [ ] 取得する個人情報の種類、利用目的、保存期間を決めたか
- [ ] 利用規約とプライバシーポリシーに、取得する情報と利用目的を書いたか
- [ ] 個人情報を外部のサービス（クラウド、AI のモデル提供元、分析ツール）に渡す場合の扱いを確認したか
- [ ] 本人からの開示・訂正・削除の求めに対応できるか
- [ ] 漏えいが起きた場合の報告の手順を決めているか
- [ ] 海外の利用者がいる場合、その国の法令（GDPR など）の対象になるか確認したか

### 4. 契約（業務委託・受託開発）

- [ ] 契約の形態（準委任、請負）と、成果物・完成の定義を確認したか
- [ ] 成果物の権利（著作権の帰属、既存のコードやライブラリの扱い）を確認したか
- [ ] 秘密保持の範囲と期間、契約終了時のデータの扱いを確認したか
- [ ] AI ツールの利用の可否と、条件を確認したか
- [ ] 損害が起きた場合の責任の範囲と上限を確認したか
- [ ] 再委託の可否を確認したか

### 5. サービス提供時の表示と規制

- [ ] 利用規約、プライバシーポリシー、特定商取引法に基づく表記（有料サービスの場合）を用意したか
- [ ] AI が応答・生成していることを、必要に応じて利用者に示しているか
- [ ] アクセシビリティへの配慮（障害者差別解消法の合理的配慮）を確認したか（[フロントエンド・UX・アクセシビリティチェックリスト](../frontend/checklist.md)）
- [ ] AI に関する法令・ガイドラインを確認したか（[事業としてのロードマップ（AI 時代の事業運営）](../business/roadmap.md) の「規制とガバナンス」）

## AI への依頼テンプレート

```markdown
あなたはソフトウェアのライセンスとコンプライアンスに詳しいアドバイザーです。
以下のプロジェクトについて、法務上の確認事項を洗い出してください。
（最終的な判断は専門家に確認する前提です）

## プロジェクトの概要
{ サービスの内容、利用者、提供する国・地域、扱う個人情報、利用している AI ツール }

## 依存パッケージ
{ 依存パッケージとライセンスの一覧 }

## 依頼内容
1. 添付のチェックリストと照らし合わせ、確認が漏れている項目を挙げてください。
2. ライセンスの条件で、注意が必要なパッケージと、その理由を挙げてください。
3. 個人情報の扱いで、確認が必要な点を挙げてください。
4. 専門家に確認すべき事項を、優先度順に挙げてください。
```
