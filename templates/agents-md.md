# AGENTS.md

> 最終確認日：2026年11月15日

AI エージェント向けの指示ファイルのひな形です。リポジトリの直下に `AGENTS.md`（Claude Code では `CLAUDE.md`）として置きます。

**書き方のポイント**

- 短く保つ。一般的な心得や、リンター・フォーマッターで守れる規約は書かない
- プロジェクト固有のこと（コマンド、構成、規約、禁止事項）だけを書く
- 詳しい手順はスキルや別の文書に分け、必要なときだけ読み込ませる
- Web などから取得した文章をそのまま入れない
- AI の見逃しや失敗があったときに、必要な1行を足していく

```markdown
# { プロジェクト名 }

{ プロジェクトの目的を1〜2文で }

## コマンド
- 依存のインストール：`{ コマンド }`
- 起動：`{ コマンド }`
- テスト：`{ コマンド }`
- リンター・型チェック：`{ コマンド }`

## 構成
- `{ ディレクトリ }`：{ 役割 }
- `{ ディレクトリ }`：{ 役割 }

## 規約
- { 例：API のレスポンスは src/utils/api-response.ts の形式を使う }
- { 例：DB へのアクセスは repositories/ を経由する }

## 完了の条件
- 完了を報告する前に、テスト・リンター・型チェックを実行し、結果を示す
- 画面を変更した場合は、ブラウザで表示を確認する

## 禁止事項
- `{ パス }` は変更しない（{ 理由 }）
- 秘密情報をコードやログに書かない
- マイグレーションで、列の削除や名前の変更を一度に行わない

## 参考
- 仕様：`{ パス }`
- 設計判断の記録：`docs/adr/`
```
