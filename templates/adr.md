# ADR（設計判断の記録）

> 最終確認日：2026年11月15日

設計上の重要な判断を、理由とともに残すためのテンプレートです。1つの判断につき1ファイルを作り、`docs/adr/0001-xxx.md` のように番号を付けて管理します。

```markdown
# { 番号 }. { 判断の題名 }

- 状態：{ 提案中 / 採用 / 廃止 / 置き換え（→ 番号） }
- 日付：{ YYYY-MM-DD }
- 決定者：{ 名前・役割 }

## 背景
{ 何を決める必要があったか、制約、前提 }

## 検討した案
1. { 案 A }：{ 長所 / 短所 / 費用 }
2. { 案 B }：{ 長所 / 短所 / 費用 }

## 決定
{ 採用した案と、その理由 }

## 影響
{ この判断で変わること、受け入れたリスク、後で見直す条件 }
```
